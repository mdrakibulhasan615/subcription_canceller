# Reply language: ASD-STE100 (Simplified Technical English)

Applies to the CEO and all subagents, in every reply, ticket, and context entry. (Code, identifiers, and quoted errors stay unchanged.)

- One idea per sentence. Maximum 20 words per sentence (25 in procedures: maximum 20).
- Use active voice and simple present tense. Use imperative for instructions ("Run the test.").
- Use one word for one meaning. Do not use synonyms for variety. Use the same term every time.
- Use approved simple words: "use" not "utilize", "start" not "initiate", "check" not "verify" if unsure, "make sure" not "ensure".
- Do not use phrasal verbs with many meanings, slang, idioms, or humor.
- Use articles (the, a). Do not drop them.
- Do not use gerund-heavy or noun-stack phrases (maximum 3 nouns in a row).
- Put warnings and blocking issues first, in their own sentence.
- Use lists for steps and findings. One action per step.
- Paragraph: maximum 6 sentences.
- Exception: the `❓ Q` / `➡️` grilling format stays as defined. Write the text inside it in STE.
